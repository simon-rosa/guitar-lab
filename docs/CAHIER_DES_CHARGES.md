# Cahier des charges

Le cahier des charges complet (vision, public cible, ~110 features classées MVP / V1 / V2, exigences techniques et roadmap) est tenu à jour dans le document de référence :

**https://claude.ai/artifact/1HPJDkHVyXwJD869fA4dmY**

## Résumé

**Objectif** : un éditeur de tablatures et partitions aussi complet que Guitar Pro 8, assez exigeant pour un usage professionnel (studio, scène, édition), plus rapide à saisir, multiplateforme et ouvert.

**Public** : musiciens professionnels (session, tournée, directeurs musicaux), arrangeurs et orchestrateurs, producteurs, profs, transcripteurs, amateurs.

**Différenciateurs** :

1. Saisie ultra-rapide au clavier, raccourcis entièrement configurables
2. Gravure de niveau éditeur : partitions, parties séparées, charts
3. Intégration studio : MIDI, VST3/AU, synchro DAW, stems
4. Mode scène fiable : setlists, pédalier, click et cues
5. Web et mobile synchronisés
6. Collaboration en temps réel
7. Transcription assistée par IA
8. Format ouvert, import Guitar Pro 3 à 8 fiable

**Roadmap** :

- **MVP** : éditer et écouter une tab.
- **Jalon 1** : bêta publique (un fichier GP5 s'ouvre et se rejoue fidèlement).
- **V1** : remplacer Guitar Pro.
- **Jalon 2** : parité avec GP8.
- **V2** : faire mieux que Guitar Pro.

L'état d'avancement de chaque feature dans le code est dans [FEATURES.md](FEATURES.md).
